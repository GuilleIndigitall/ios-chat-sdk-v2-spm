# Indigitall iOS Chat SDK

Swift Package Manager distribution of the Indigitall iOS Chat SDK.

## Add the package

In Xcode, add this repository:

https://github.com/GuilleIndigitall/ios-chat-sdk-v2-spm.git

Select the IndigitallChatSDK product. The current release is 0.1.1.

The package dependencies are declared in Package.swift.
